**Post:**

Van der Waerden numbers again. OpenAI's preprint: c = 1/100000 in k^(c·k·log₂r). This repo got c to 1/25, and an open barrier note says its style of proof can't pass 1/24.

Today's PR (conditionally) reaches c = 1/16, 6250× the original, by counting bad events differently. 🧵

---

**Thread, 1/4.** A coloring fails if some k-term progression is one color. The old proof union-bounds over all N² progressions, and rules each one out with about γk/2 independent random flips. That trade-off is exactly where c < γb/4 < 1/24 comes from.

**2/4.** Open PR #4 (Artus Krohn-Grimberghe) noticed you don't always need the whole progression. When "keys" repeat, the repeated keys alone certify the failure, and those key sets need only about N names instead of N². That gives every c < 1/18.

**3/4.** New here: sort progressions by the "carry rank" ρ of the classes holding repeated keys. Their key sets need only about q^(2ρ) names, whatever the starting point. And each class pins one integer equation on the step, so only N²/q^ρ progressions have rank ρ.

**4/4.** Either many flips land in those classes (cheap certificate) or many distinct keys flip (cheap count). The worst rank is ρ = D/2, where the cost on c is 5/2, down from 3 (#4) and 4 (before). So every c < 1/15 works; c = 1/16 is certified in exact arithmetic.

Caveat: conditional on OpenAI's geometric/counting lemmas and on #4's repeated-key structure (restated with proofs), not independently reviewed, no finite record. Chart + proof in the repo.
